# 데일리 뉴스레터 루틴 운영 메모

매일 아침 뉴스레터 한 편을 자동으로 써서 `main`에 푸시하고, GitHub Actions가 iruki.dev에 배포합니다.

## 설계 요약

**운영 모델은 일간지입니다.** 지면 크기(분량)는 매일 고정, 구성은 그날 뉴스 물량에 따라 유동적으로 바뀝니다.

- **분량** 본문 12,000~17,000자 (읽는 데 25~35분) — 매일 반드시 채웁니다
- **구조** 레이어드: 여는 글 → 헤드라인 → 딥다이브 3~4꼭지 → 분야별 브리핑 15~20건 → 코너 2~4개 → 닫는 글
- **범위** 정치·정책 / 경제·시장 / 산업·기업 / 테크·개발 / 세계 / 사회·생활 — 매일 전부 훑습니다
- **중립** 해석(배경·맥락·이해관계)은 쓰되 의견(평가·당위·단정적 예측)은 쓰지 않습니다
- **소재가 적은 날** 문장을 늘리지 않고 상비 코너(깊게 보기 · 트렌드 관찰 · 가벼운 읽을거리 · 오늘의 단어)를 늘려서 지면을 채웁니다

## 구성 요소

| 위치 | 역할 |
|---|---|
| [`.claude/newsletter/PROMPT.md`](PROMPT.md) | **루틴이 따르는 사양서 전체.** 톤·구성·분량·사실확인 규칙은 이 파일만 고치면 됩니다 |
| `content/newsletter/YYYY-MM-DD.md` | 발행된 레터 한 편 (= `/newsletter/YYYY-MM-DD`) |
| `content/pages/newsletter.json` | 목록 페이지 `/newsletter` |
| `config/collections.json` | `newsletter` 컬렉션 정의 |

## 루틴 등록

Claude Code web → **Routines** → 새 루틴:

- **Schedule**: `0 21 * * *` (UTC 기준 = 한국 시각 매일 **오전 6시 시작**)
- **Environment**: 이 저장소(`iruki-dev/iruki-dev.github.io`)가 붙은 환경
- **Session**: 매 실행마다 새 세션 (fresh session per fire)
- **Prompt**:

```
iruki.dev 저장소에서 오늘자 아침 뉴스레터를 발행하세요.

먼저 `.claude/newsletter/PROMPT.md`를 처음부터 끝까지 읽고, 거기 적힌 순서와 규칙을 그대로 따르세요.
그 문서가 이번 작업의 유일한 기준입니다. 문서에 없는 판단이 필요하면 보수적으로 — 확인되지 않은 내용은 쓰지 않는 쪽으로 — 결정하세요.
```

> **시작 시각을 발행 희망 시각보다 앞당겨 잡으세요.** 검색 25~40회에 12,000자 집필이라 한 번 실행에 20~40분이 걸립니다. 오전 7시에 읽고 싶다면 6시에 시작해야 합니다. 한국 시각 = UTC + 9시간이므로 cron의 시(hour)에서 9를 빼면 됩니다.

## 튜닝 가이드

프롬프트는 한 번에 완성되지 않습니다. 초반 1~2주는 아침에 결과물을 훑고, 어색했던 부분을 그때그때 `PROMPT.md`에 반영하는 것을 권합니다.

| 증상 | 고칠 곳 |
|---|---|
| 문장이 늘어지고 알맹이가 없음 | 8장 "이렇게 채우면 안 됩니다"에 실제로 거슬린 표현을 추가. 추상적 지시보다 금지 표현을 늘리는 쪽이 훨씬 잘 먹힙니다 |
| 분야가 한쪽으로 쏠림 | 3장의 여섯 분야 표에서 검색 방향을 구체화하거나, 4장 재배분 표의 꼭지 분배 규칙을 조정 |
| 편향된 문장이 보임 | 7장 표의 "쓰면 안 되는 것" 열에 실제 문장을 예시로 추가 |
| 분량이 매번 미달 | 4장 지면 배분표의 코너 개수를 늘리거나, 3장 리서치 예산(검색·열람 횟수)을 올림 |
| 딥다이브가 얕음 | 5장 ③의 `어떻게 여기까지 왔나요` 문장 수 하한을 올리고, 3장 2단계 검증 대상을 확대 |
| 코너를 늘리거나 줄이고 싶음 | 5장 ⑤의 A~D 코너 정의를 수정 (`오늘의 단어`만 매일 고정) |

## 운영 팁

- **레터가 안 올라온 날**: 루틴 실행 기록의 마지막 보고를 확인하세요. `PROMPT.md` 11장의 중단 조건(이중 발행 · 빌드 실패 · 검색 도구 불가)에 걸리면 일부러 발행하지 않고 보고만 남깁니다. **분량 미달은 중단 사유가 아닙니다** — 취재를 더 해서 채우도록 지시돼 있습니다.
- **국내 언론사 봇 차단**: 프롬프트 3장에 4단계 폴백(다른 매체 → 통신사·해외 매체 → 원 출처 → 숫자 빼고 확인된 범위만)이 들어 있습니다. 특정 매체가 반복해서 막히면 그 매체를 우회하도록 폴백 순서를 조정하세요.
- **아카이브가 쌓이면**: 최근 7일 중복 확인은 파일 목록으로 하고 있어 비용이 낮습니다. 다만 몇 달 뒤 "이어지는 이야기" 코너를 넣고 싶어지면 5장 ⑤에 코너를 추가하세요.
